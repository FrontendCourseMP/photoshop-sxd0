# Image Processing Lab

Веб-приложение для лабораторных работ по предмету «Обработка изображений / Технологии компьютерной графики».

## Деплой

Ссылка на хостинг: `https://delightful-faun-d6c0a2.netlify.app/`

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Проверка линтером:

```bash
npm run lint
```

## Реализовано

- Загрузка изображений PNG, JPG/JPEG и GB7.
- Отображение изображения на HTML5 canvas.
- Экспорт изображения в PNG, JPG и GB7.
- Собственный кодер и декодер формата GrayBit-7.
- Строка состояния с форматом, размером, глубиной цвета, маской, масштабом и активными каналами.
- Панель каналов с превью и переключением grayscale/RGB/alpha каналов.
- Инструмент «Пипетка»: координаты пикселя, RGB, Alpha и CIELAB.
- Диалог Levels: гистограмма, linear/log режим, Master и отдельные каналы, preview, reset, cancel, apply.
- Масштаб просмотра от 12% до 300% с билинейной интерполяцией.
- Диалог изменения размера: проценты/пиксели, связь сторон, nearest neighbor и bilinear, валидация.
- Фильтры 3×3: identity, sharpen, Gaussian blur, box blur, Prewitt X/Y.
- Медианный фильтр 3×3.
- Выбор каналов фильтрации и стратегии обработки краёв: black, white, copy.
- Асинхронная обработка фильтров с прогрессом, чтобы интерфейс не блокировался полностью.
